# 教案格式规范

本文件记录参考教案（第3课）的精确版式参数，供生成脚本 1:1 复刻。

## 1. 页面设置

| 参数 | 值 |
|------|-----|
| 纸张 | A4 纵向 |
| 页宽 | 11906 twips (21cm) |
| 页高 | 16838 twips (29.7cm) |
| 上边距 | 1440 twips (2.54cm) |
| 下边距 | 1440 twips (2.54cm) |
| 左边距 | 1797 twips (3.17cm) |
| 右边距 | 1797 twips (3.17cm) |
| 文档网格 | linePitch=312, 固定行距 15.6磅 |
| 页眉页脚 | 无 |

## 2. 正文顶部段落

### P0: 标题行
- 文字：「五年级信息科技」
- 对齐：居中
- 字体：宋体、加粗、小三（15pt / sz=30）

### P1: 空段
- 间距：段前 0、段后 0，行距固定 15.6 磅
- 作用：留出标题与信息行之间的间距

### P2: 信息行
- 文字：「设计者：张 根    第 X 周    授课时间：    」
- 字体：宋体、加粗、小四（12pt / sz=24）
- 设计者姓名、周次、授课时间带下划线

## 3. 主体表格

- 边框：全框单线，1/4 磅（sz=4）
- 列数：6 列

### 单元格样式

**标签单元格**（如「班级」「课题」「教学目标」等）：
- 字体：宋体、加粗、小四（12pt）
- 对齐：水平居中、垂直居中
- 底纹：无

**内容单元格**：
- 字体：宋体、不加粗、小四（12pt）
- 对齐：水平左对齐、垂直居中
- 行距：固定 20 磅（400 twips, lineRule=exact）

**教学设计内容区**：
- 环节标题段：宋体、加粗、小四、行距固定 20 磅
- 正文段：宋体、不加粗、小四、行距固定 20 磅
- 每行约 28 个汉字

## 5. 两页校准机制

- **固定部分**：R1-R8 行高合计约 4104 twips（约 7.24cm）。
- **教学设计区**：每段行高 400 twips（20磅），约 28 字/行。
- **课后反思行**：行高动态调整，通过 Word COM 真实读取页数后二分搜索最优行高。
- **目标**：页数 = 2，第二页底部不留大片空白。
- **安全范围**：教学设计正文 600-980 字 / 17-27 段时可稳定排满两页。
