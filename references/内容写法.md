# 教案内容写法参考

本文件记录教案各栏目的内容撰写规范、271 教学模式、八种阳光卡的使用方式与示例。

## 1. 271 教学模式

每课时按 **2:7:1** 时间分配：

| 环节 | 时长 | 占比 | 内容 |
|------|------|------|------|
| 导入 | 约2分钟 | 2/10 | 情境导入、复习引入、问题驱动、激趣 |
| 教学 | 约7分钟 | 7/10 | 新授、探究、实践、操作（主要环节） |
| 反思/拓展 | 约1分钟 | 1/10 | 总结归纳、反思提升、拓展延伸 |

### 教学设计中 271 的体现

教学设计正文按三大板块组织：

```
一、情境导入（2分钟）（阳光卡）
  正文...
二、探究新知 / 实践操作（7分钟）（阳光卡）
  活动1：...
  正文...
  活动2：...
  正文...
三、总结拓展（1分钟）（阳光卡）
  正文...
```

## 2. 八种阳光卡

在合适的教学环节发放对应阳光卡，在教学设计正文中用括号标注。

| 阳光卡 | 适用环节示例 | 触发场景 |
|--------|-------------|---------|
| 乐学与善思 | 导入环节 | 学生主动思考、对课题产生兴趣 |
| 实践与运用 | 教学-操作环节 | 学生动手操作、上机实践 |
| 劳动与创造 | 教学-创作环节 | 学生创作作品、完成综合任务 |
| 阅读与表达 | 导入/分享环节 | 学生朗读、口头表达、分享交流 |
| 分析与质疑 | 教学-探究环节 | 学生提出问题、分析推理 |
| 合作与探究 | 教学-小组环节 | 学生小组合作、探究学习 |
| 总结与反思 | 总结环节 | 学生回顾总结、自我反思 |
| 自主与管理 | 全程 | 学生自主学习、课堂纪律管理 |

### 阳光卡标注格式

在环节标题后用括号注明：

```
一、情境导入（2分钟）（乐学与善思）
二、探究新知（7分钟）（分析与质疑）（合作与探究）
三、总结拓展（1分钟）（总结与反思）
```

- 一个环节可标注多张卡（用多个括号或一个括号内并列）。
- 不强制每环节都有卡，根据环节性质选择最合适的 1-2 张。

## 3. 各栏目写法规范

### 教学目标

3条，编号 1/2/3，涵盖：
1. **知识与技能**：了解/理解/掌握什么概念、能做什么操作。
2. **过程与方法**：通过什么活动/方法，培养什么能力。
3. **情感态度与价值观**：培养什么思维品质/习惯/意识。

示例：
```
1. 了解算法的基本概念，知道算法是解决问题的一系列明确步骤。
2. 通过游戏体验活动，能够将简单问题分解为有序步骤，培养计算思维。
3. 感受算法在生活中的广泛应用，激发学习信息科技的兴趣。
```

### 重点难点

2条，分别写重点和难点：
```
重点：理解算法是解决问题的一系列明确步骤。
难点：将实际生活问题抽象为算法步骤，用自然语言描述。
```

### 教法学法

一行概述，常用方法：
```
任务驱动法、游戏教学法、小组合作法
```

### 教学准备

一行概述：
```
多媒体教室、PPT课件、游戏素材、学习任务单
```

### 板书设计

2-4行，呈现核心板书布局：
```
第3课 游戏体验寻规律

算法 → 解决问题的步骤
输入 → 处理 → 输出
```

### 教学设计正文（核心）

**结构**：按 271 模式三大板块，每个板块含标题段 + 正文段。

**段落数控制**：总计 17-27 段（含标题段），正文约 600-980 字。

**环节标题**（kind="title"）：
```
一、情境导入（2分钟）（乐学与善思）
二、探究新知（7分钟）（分析与质疑）
三、总结拓展（1分钟）（总结与反思）
```

**活动小标题**（kind="sub"）：
```
活动1：走迷宫游戏体验
活动2：分析游戏步骤
```

**正文**（kind="body"）：
```
教师出示走迷宫游戏，请一位同学上来试玩。其他同学观察并思考：
他是怎么找到出口的？用了哪些策略？
引导学生讨论：玩游戏的过程其实就是在执行一系列步骤。
```

## 5. 注意事项

- 教学设计正文控制在 **600-980 字 / 17-27 段**，太少排不满两页，太多会溢出第三页。
- 阳光卡选择要**匹配环节性质**，不要每个环节都塞满所有卡。
- 271 时间分配是**比例**，不是绝对分钟数，实际课时可能 40 分钟或 35 分钟。
- 课题名称须与教材目录一致。
- 教学目标必须三条，分别对应知识技能、过程方法、情感态度。
